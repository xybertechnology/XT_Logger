# XT_Logger
XyberTechnology Logger - A Failed Authentication/Failed Password Attempt Logger

# Roadmap
- Better read/log caching for better parsing times

- Automate logging findings to a file for purposes including auditing and persistent storage of records.

- Automating the script to be ran periodically using cron.

# Instructions
To run the script on an Ubuntu system, run the following command:

sudo ./path/to/XT_Logger.sh # Replace path/to/ to where you saved the script.
